Свой GA4

Прямое подключение · без чужих коннекторов · Pinterest склеен

Разовая настройка — минут пятнадцать

  1. Открой console.cloud.google.com и создай проект (любое имя).
  2. В разделе APIs & Services → Library включи два API: Google Analytics Data API и Google Analytics Admin API.
  3. APIs & Services → OAuth consent screen: тип External, заполни название и почту, в Test users добавь свой гугл-аккаунт. Публиковать приложение не нужно.
  4. Credentials → Create credentials → OAuth client ID, тип Web application. В Authorized JavaScript origins впиши домен, откуда откроешь этот файл — например https://твой-логин.github.io. Без пути, только домен.
  5. Скопируй Client ID и вставь ниже. Чтобы не вставлять каждый раз, впиши его в константу CLIENT_ID в начале скрипта.

Файл должен лежать на https://-домене из шага 4. С локального диска авторизация Google не работает — это его требование, обойти нельзя.

Откуда приходят

GA4 разносит Pinterest на pinterest.com / referral и Pinterest / organic. Здесь они сложены — иначе доля канала выглядит вдвое меньше реальной.
