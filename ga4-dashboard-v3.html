Обзор статистики

Разовая настройка

  1. console.cloud.google.com → создай проект.
  2. APIs & Services → Library: включи Google Analytics Data API и Google Analytics Admin API.
  3. OAuth consent screen: тип External, себя добавь в Test users.
  4. Credentials → OAuth client ID → Web application. В Authorized JavaScript origins — только домен, например https://alena-shilkina.github.io.
  5. Client ID впиши в константу CLIENT_ID в начале скрипта.
